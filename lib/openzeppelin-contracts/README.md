# Vendored OpenZeppelin subset

The following source files and `LICENSE` are copied unchanged from the
[OpenZeppelin Contracts v5.0.2 release](https://github.com/OpenZeppelin/openzeppelin-contracts/tree/v5.0.2):

- `contracts/token/ERC20/ERC20.sol`
- `contracts/token/ERC20/IERC20.sol`
- `contracts/token/ERC20/extensions/IERC20Metadata.sol`
- `contracts/utils/Context.sol`
- `contracts/interfaces/draft-IERC6093.sol`

This is the complete transitive Solidity dependency set used by ThoughtToken.
The upstream MIT license is included beside this file. No install or network
fetch is performed by builds. Foundry maps `@openzeppelin/contracts/` to
`lib/openzeppelin-contracts/contracts/`.
